## 3. Corrections to the library's documentation-based workflows (found live)

These are the points where the MSU instance, as observed, differs from or narrows what the library files under /home/claude/brightspace-library/references/ say. The library was not edited; the corrections are recorded here for whoever maintains it.

1. quiz-special-access.md: "Set Override time limit and Set time limit to 45 minutes, or use the 1.5 multiplier." There is no multiplier on the quiz special access dialog. The Add Special Access to Quiz dialog offers Override time limit > Set time limit > New Time Limit in minutes (default 120) plus the three "When The Time Limit Expires" options, and Override attempts allowed. For a 30-minute quiz the workflow should say "Set time limit = 45". Observed radio wording: "Allow selected users special access to this quiz" / "Allow only users with special access to see this quiz". (Inventory screen quiz-add-special-access-dialog.)
2. quiz-accommodations.md: confirmed live. The multiplier lives in Classlist > learner chevron > Edit Accommodations > Quizzes > Timing > "Modify Time Limit", with radios "Multiplier of original quiz time" (textbox default 1, unit "times") and "Extra time" (textbox default 0, unit "minute(s)"). The library's "Select Modify Time" should read "Modify Time Limit"; the Extra time alternative is not mentioned in the library and should be. (Inventory screen classlist-edit-accommodations.)
3. Manage Grades New Item: switching from the Properties tab to the Restrictions tab with a valid Name saves the item immediately (page becomes "Edit Item: <name>", URL item_rests_edit.d2l?...&objectId=<id>&feedback=1&d2l_isfromtab=1). Cancel on the Restrictions tab does not undo that save. Any workflow that says "fill in Properties, then look at Restrictions, then Cancel" creates an item. Name validation rejects / " * < > + = | , % and an empty Name is refused with "Name is required." (Inventory screens grades-new-item-numeric and grades-edit-item-restrictions.)
4. Import and Export are buttons on the Enter Grades tab (Import primary, then Export, Switch to Spreadsheet View, More Actions). Manage Grades > More Actions holds only Reorder, View Event Log, Make Visible to Users, Hide from Users, Delete. gradebook-lab.md and the tour card already say "Enter Grades > Export"; any text that puts Import/Export under Manage Grades is wrong for this instance. (Inventory screens grades-enter-grades and grades-manage-more-actions-menu.)
5. Selectbox grade items are disabled on the New Item type chooser until a course-level grade scheme exists: "Note: Selectbox type grade items cannot be created until at least one org unit grade scheme has been created." The organization scheme "Percentage" does not count. The library's list of six item types (behaviour-rules G16) is correct, but a workflow that creates a Selectbox item must create a scheme first. (Inventory screen grades-new-item-type.)
6. final-grade-release.md: "select that learner's score under Final Calculated Grade, select Release Final Calculated Grade and Save and Close." The observed route is Enter Grades > Final Calculated Grade column chevron ("View Actions for Final Calculated Grade") > Enter Grades, which opens the Final Grades page. There, per learner: tick the "Released" checkbox (aria "Release Final Calculated Grade to <learner>") and Save; course-wide: title chevron > Release All, then Save. The title chevron menu is View Event Log, Recalculate All, Transfer All, Clear All, Add Feedback for All, Release All, Unrelease All. Clicking the learner's own cell was not tried. (Inventory screen grades-final-grades.)
7. Grades tool entry: Assessments > Grades opens /d2l/lms/grades/index.d2l?ou=<ou>, which lands on the Setup Wizard while the course has no grade items and on Enter Grades once an item exists. A guessed /d2l/lms/grades/admin/manage/main.d2l returned Page Not Found.
8. Changing the Grading System on Calculation Options asks two confirmations ("You are about to save changes. Are you sure you want to continue?" then "Are you sure you want to change the Grading System for the org unit?"), then shows "Saved successfully". Workflows that say "click Save" need both Yes clicks.
9. behaviour-rules.md Q3 marks the Timer Settings alternatives ("Flag as exceeded time limit...", "Do nothing...") as UNCONFIRMED. They exist on this instance, in both the quiz editor's Timing dialog and the quiz special access dialog, with the wording "Flag as \"exceeded time limit\" and allow the learner to continue working" and "Do nothing: the time limit is not enforced".
10. behaviour-rules.md G29 quotes the auto-zero label as "Automatically assign 0 to missing submissions". The live label is "Automatically apply a grade of zero (0) to missing submissions once an assessment becomes overdue" under the heading "Automatic Zero for Missing Submissions".
11. behaviour-rules.md A5 quotes the assignment special access option as "Allow only users with special access to see this assignment". The live label says "folder": "Allow only users with special access to see this folder", and the first option is "Allow users with special access to submit outside the normal availability dates for this folder".
12. The Classlist learner menu is Send Email, Impersonate, View progress, View groups, Edit Accommodations; behaviour-rules G35 mentions "Manage Exemptions" on the Classlist, which was not in this menu. Exemptions were reachable from the Enter Grades learner chevron as "Bulk edit exemptions".
13. The assignment and quiz editors are the new activity editor (left column plus right-hand collapsible panels), not the classic tabbed form. Cancel prompts "Discard changes?" / "Are you sure you want to discard your changes?" (Yes / No).
