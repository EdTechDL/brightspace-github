Project overview

Brightspace Support Assistant

A practice environment for new support staff who resolve instructor tickets in D2L Brightspace, a large and highly configurable learning platform. Built so a new hire can rehearse real fixes before touching a live course.

The problem

New support staff answer tickets about a system they may never have used, and a wrong click in a live course changes real grades. The documentation exists, but it is scattered and not organized around the questions instructors actually ask.

What is inside

  • 25 ticket scenarios, searchable by symptom, each with diagnostic checks and sources
  • 10 guided walkthroughs with on-screen highlights and explanation bubbles
  • A working gradebook backed by 26 calculation checks: drops, exemptions, bonuses, caps
  • 59 help cards: click any of the 44 Course Admin tools to see what it is for, when support uses it, and what to check

What AI did

Claude and Codex captured interface labels from a practice sandbox, drafted walkthrough text, compiled vendor documentation, and wrote and refactored the simulator code.

What I did

Chose what to build from the tickets new staff actually receive. Tested every step in a sandbox, rewrote inaccurate explanations, and labeled anything unverified as simulated. Wrote the calculation tests from worked examples, so the math is checked rather than trusted.

Written once, for people and for AI

Each solved ticket becomes an anonymized workflow in a structured library. The same files that drive these explanations can be handed to an AI assistant, so it answers with verified steps instead of guessing. The Learning notes and AI instructions screen exports them.

What changed

I got up to speed on the platform's support work quickly, every fix is now captured instead of living in one person's head, and colleagues asked to turn the method into onboarding for future hires.

Where to start

Sample data only. Nothing here connects to a live system. Explanations are on: click anything to learn what it does. Use Explain clicks at the bottom of the screen to turn them off.
