# Extra time across a course's quizzes

ID: quiz-accommodations. Documentation checked: 2026-09-22. Institution verified: no.

Example: “Give the demo learner 50% extra time on all quizzes in this course.” Confirm the course, intended multiplier, existing accommodations, quiz-specific exceptions, and whether any relevant attempt has already started. Implement the supplied accommodation; determining a learner's eligibility is outside this procedure.

Open **Classlist** from the course navigation or Course Admin. Find the learner, open their menu, and choose **Edit Accommodations**. Select **Modify Time**, choose **Multiplier of original quiz time**, enter **1.5**, and **Save**. This requires the relevant accommodation permission. Special Access may override the course accommodation for a particular quiz. [D2L: Manage Classlist accommodations](https://community.d2l.com/brightspace/kb/articles/34430-manage-classlist-accomodations)

Reopen the learner's accommodation dialog to inspect the saved multiplier. In the sandbox, test two quizzes with different base limits using an approved demo learner; for example, 20 and 40 minutes should become 30 and 60 minutes when no overriding special access exists. Ordinary Quiz Preview does not apply accommodations. [D2L: Preview limitations](https://community.d2l.com/brightspace/kb/articles/35012)

Do not promise a retroactive update to an in-progress attempt. D2L distinguishes accommodation/special-access changes from other settings applied after a quiz starts; inspect the specific attempt and current documentation before advising. [D2L: Quizzes with attempts](https://community.d2l.com/brightspace/kb/articles/5197-manage-quizzes-with-learner-attempts)

Save the reusable course-level workflow with anonymized parameters and the actual verification performed. Do not retain the learner's identity or accommodation rationale in the general library.
