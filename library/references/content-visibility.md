# Make hidden content visible

ID: content-visibility. Documentation checked: 2026-09-22. Institution verified: no.

Example: “Students cannot see Week 1.” First check the course is accessible and determine whether the problem concerns one learner or everyone. Visibility, access dates, release conditions, and course access are different causes.

For the first sandbox exercise, hide Week 1 with no other restrictions. In Classic Content, use the module's context menu → **Make Visible to Users**. In New Content Experience, select the unit and set its visibility toggle to **Visible**. Match the route to the actual screen.

Explain that instructor access can show content a learner cannot see. Reopen the item to confirm its saved visibility. Use the available learner-role view as a visibility check, and record its limitations for learner-specific conditions.

A reusable completion note should identify what was hidden, the change made, and the exact verification performed. Do not call an access problem fixed merely because the instructor sees the item.

Sources: [Classic Content](https://community.d2l.com/brightspace/kb/articles/3382-hide-content-topics-modules-and-downloads), [Content experiences](https://community.d2l.com/brightspace/kb/articles/5314-content-experiences).
