# Keep late submissions open

ID: assignment-dates. Documentation checked: 2026-09-22. Institution verified: no.

Example: “Due Friday at 11:59 p.m.; accept late submissions until Sunday at 11:59 p.m.” This recipe assumes a visible assignment and a course-wide request. A one-learner extension needs the relevant exception workflow instead.

Start with Due Date and End Date both Friday. In **Assignments**, locate the assignment's actions menu → **Edit Assignment**. Keep **Due Date** Friday. Open **Availability Dates & Conditions**, set **End Date** Sunday, then **Save and Close**. Use explicit calendar dates and the actual displayed time zone.

Explain that the due date communicates the deadline while the end date stops submissions. Availability choices affect appearance outside the access window.

Reopen the assignment and inspect both saved dates. For a practical sandbox test, use short test windows and a demo learner to submit after the due date but before the end date. If no learner test was possible, report the configuration check only.
