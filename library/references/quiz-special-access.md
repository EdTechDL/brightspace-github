# Extra time on one quiz

ID: quiz-special-access. Documentation checked: 2026-09-22. Institution verified: no.

Example: “Give one demo learner 50% extra time on Quiz 1 only.” Establish whether the request concerns one quiz or all quizzes, an existing attempt, extra time, another attempt, or different dates. Those requests can require different handling.

For all quizzes in one course, load [quiz-accommodations.md](quiz-accommodations.md). Do not repeat this fixed-duration example across quizzes with different limits.

Practice state: a 30-minute quiz and a demo learner without another time accommodation. Open **Quizzes** → target quiz menu → **Edit** → **Availability Dates & Conditions** → **Manage Special Access**. Choose **Allow selected users special access to this quiz**, then **Add Users to Special Access**. Set **Override time limit** and **Set time limit** to 45 minutes, or use the 1.5 multiplier. Select the demo learner and save the exception and quiz.

Explain that “Allow only users with special access to see this quiz” changes who can access the quiz; it is a different option from granting an exception.

Reopen the saved special-access record and check the learner and 45-minute limit. Confirm the default remains 30 minutes. Ordinary Quiz Preview does not apply special access or accommodations. A demo-learner check can establish the actual learner outcome; otherwise record configuration-only verification.

Sources: [Special-access settings](https://community.d2l.com/brightspace/kb/articles/3413-create-and-configure-a-quiz), [Preview limitations](https://community.d2l.com/brightspace/kb/articles/35012).

Use 45 for a 30-minute quiz. The multiplier and Extra time live in Classlist > Edit Accommodations.
