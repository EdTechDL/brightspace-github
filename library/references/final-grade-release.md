# Release a calculated final grade

ID: final-grade-release. Documentation checked: 2026-09-22. Institution verified: no.

Example: “The learner sees individual marks but not the final course total.” First establish that the missing value is the final total and that the course uses Calculated Final Grade. This is not the same as an unpublished assignment evaluation or a hidden individual column.

Practice state: the demo learner's final calculated score is correct but unreleased. Open **Grades** → **Enter Grades** → select that learner's score under **Final Calculated Grade**. Select **Release Final Calculated Grade** and **Save and Close**. Match the current interface before applying this documented route. A course configured to release Adjusted Final Grade needs its corresponding workflow.

Use the learner's menu → **Preview** within Enter Grades to inspect what is visible. Report this as a visibility check, not proof that the calculation follows the syllabus. Grade calculation, final-grade type, and release are separate decisions.

Sources: [Enter and release grades](https://community.d2l.com/brightspace/kb/articles/34125-enter-grades-in-the-grades-tool), [Preview methods](https://community.d2l.com/brightspace/kb/articles/35012).
