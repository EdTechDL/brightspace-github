Help cards keyed by help id (`<screen>.<section>.<control>[.<option>]`).
Every file in this folder is merged into one registry at build time; split them by tool.
Schema: title, where, what, when, options[], learnerSees, howTo[], verify, gotchas[],
tickets[], related[], msu, source, evidence (captured | documented | simulated).
Any control with no entry shows an authoring-gap card and counts as untaught in the audit.
